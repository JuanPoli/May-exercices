# May · Mi ritmo

Plan de 52 semanas, cuatro días por semana. Incluye 11 demostraciones visuales generadas con IA, instrucciones, progresiones opcionales, seguimiento local y exportación de calendario.

## Activar GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save.

Dirección prevista: https://juanpoli.github.io/May-exercices/

## Calendario

Importar `calendario_52_semanas.ics` en un calendario separado de Google Calendar. Incluye 208 eventos desde el 16/11/2026 a las 18:30 de Argentina, con aviso al inicio y enlaces a cada sesión. Revisar los permisos de notificación. Si ya importaste la versión anterior, reemplazar ese calendario para evitar duplicados.

El HTML permite cambiar el lunes inicial y la hora, y volver a exportar. El registro se guarda solamente en el navegador.

## Alcance

Plan orientativo: avanzar según técnica y recuperación, no solamente por fecha. Las imágenes son referencias generadas, no evaluación profesional. Consultar instrucciones y adaptaciones de cada ejercicio.
